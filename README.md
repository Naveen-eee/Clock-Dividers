# Clock Divider & Frequency Synthesizer (Verilog HDL)

A collection of Verilog HDL implementations of basic clock divider circuits. This project demonstrates how digital counters can be used to generate lower-frequency clocks from a high-frequency system clock.

The designs were developed and simulated using **Xilinx Vivado Simulator** and focus on understanding clock division, duty cycle, and counter-based frequency synthesis.

---

## Project Objectives

- Understand clock division using digital counters.
- Design even and odd clock dividers.
- Learn the relationship between frequency, period, and duty cycle.
- Build a strong foundation for UART, SPI, PWM, timers, and other communication protocols.

---

## What is a Clock Divider?

A **Clock Divider** is a sequential circuit that generates a lower-frequency clock from a higher-frequency input clock by counting clock cycles.

Example:

Input Clock = **100 MHz**

Divide by 2

Output Clock = **50 MHz**

Divide by 4

Output Clock = **25 MHz**

---

## Frequency Formula

\[
F_{out}=\frac{F_{in}}{N}
\]

Where:

- **Fout** = Output Clock Frequency
- **Fin** = Input Clock Frequency
- **N** = Division Ratio

Example:

```
Fin = 100 MHz
N = 5

Fout = 100 / 5 = 20 MHz
```

---

## Period Formula

The clock period is the inverse of frequency.

\[
T=\frac{1}{F}
\]

Where

- **T** = Clock Period
- **F** = Clock Frequency

Example:

```
100 MHz

T = 10 ns
```

## Even Clock Division

Even clock dividers use **toggle logic**.

Example:

Divide by 2

```
clk_out <= ~clk_out;
```

Examples

- Divide by 2
- Divide by 4
- Divide by 8

These can easily generate approximately **50% duty cycle** clocks.

---

## Odd Clock Division

Odd clock dividers cannot achieve an exact 50% duty cycle using only the positive clock edge.

Instead, the output is generated by decoding the counter state.

Examples

Divide by 3

```
LOW  = 2 clocks
HIGH = 1 clock
```

Divide by 5

Possible duty cycles

- 60% HIGH / 40% LOW
- 40% HIGH / 60% LOW

Both generate the correct output frequency.
